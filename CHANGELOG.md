# Changelog / 更新记录

## 1.0.1 — 2026-11-01

Initial public release / 首次公开发布。

- Create Bear notes from one selected OmniFocus task, including its title, tags, project and original note text.
- Use the canonical `omnifocus:///task/…` URL and append the returned Bear note link to the original task.
- Reopen an existing linked note, guard in-flight duplicate creation, and provide recovery information on failure.
- Include English and Chinese documentation, the MIT license, behavior tests and release checksum generation.

- 从单个所选任务创建 Bear 笔记，包含标题、标签、所属项目和原备注文本。
- 使用标准 `omnifocus:///task/…` 链接，并将返回的 Bear 链接追加到原任务。
- 支持打开已有笔记、防止进行中的重复创建，以及失败后的链接恢复。
- 提供中英双语文档、MIT 协议、行为测试和发布文件校验值。
